===============================================================================
  รายการ MQTT Topic ทั้งหมดของโปรเจกต์ออตโต้บอท
  (ไฟล์นี้เป็นเอกสารอ้างอิงอย่างเดียว เว็บไม่ได้อ่านไฟล์นี้)
  ชื่อ topic จริงที่เว็บใช้ ตั้งค่าได้ที่ config/mqtt.txt
===============================================================================

  ทิศทาง:   [→ หุ่น]  เว็บส่งไปให้ออตโต้บอท   (หุ่นต้อง subscribe)
            [→ เว็บ]  ออตโต้บอทส่งมาให้เว็บ  (เว็บ subscribe ให้แล้ว)


-------------------------------------------------------------------------------
[→ หุ่น]  ottobot/cmd                 คีย์ในไฟล์ตั้งค่า: TOPIC_CMD
-------------------------------------------------------------------------------
  คำสั่งท่าทางและสีหน้า ส่งเป็น JSON

  {
    "motion": "walk",               ชื่อคำสั่งท่าทาง (ดูรายการด้านล่าง)
    "face": "happy",                สีหน้าที่จะแสดง (ดูรายการด้านล่าง)
    "ts": 1700000000000             เวลาที่ส่ง (มิลลิวินาที)
  }

  หมายเหตุ  - "motion" เป็นชื่อคำสั่งเท่านั้น ไม่มีการส่งมุมข้อต่อมาให้แล้ว
              ฝั่งเฟิร์มแวร์เป็นคนกำหนดเองว่าแต่ละคำสั่งขยับอย่างไร
            - เว็บตรวจชื่อคำสั่งให้แล้ว ถ้าไม่ตรงรายการจะไม่ถูกส่งออกมาเลย
              ดังนั้นค่าที่หุ่นได้รับจะอยู่ใน 13 คำสั่งนี้เสมอ
            - ถ้าเป็นการสั่งเปลี่ยนสีหน้าอย่างเดียว จะ "ไม่มี" คีย์ motion มาด้วย
              เช่น  { "face": "love", "ts": 1700000000000 }
              ให้เช็คว่ามีคีย์ motion หรือไม่ ก่อนสั่งขยับทุกครั้ง
            - ถ้า AI ตอบโดยไม่ต้องขยับตัว จะไม่มีข้อความส่งมาที่ topic นี้เลย


-------------------------------------------------------------------------------
[→ หุ่น]  ottobot/speech              คีย์ในไฟล์ตั้งค่า: TOPIC_SPEECH
-------------------------------------------------------------------------------
  ข้อความที่ให้ออตโต้บอทพูดออกลำโพง

  {
    "text": "สวัสดีครับ",           ข้อความภาษาไทย
    "face": "happy",                สีหน้าขณะพูด (อาจไม่มี)
    "lang": "th-TH",
    "ts": 1700000000000
  }


-------------------------------------------------------------------------------
[→ หุ่น]  ottobot/control/out         คีย์ในไฟล์ตั้งค่า: TOPIC_CONTROL_OUT
-------------------------------------------------------------------------------
  คำสั่งควบคุมจากเว็บไปหุ่น ส่งจากแท็บ "สั่งเอง" บนหน้าเว็บ
  รูปแบบอิสระ ผู้ใช้พิมพ์อะไรก็ส่งอย่างนั้น เช่น

  { "action": "ping" }
  { "action": "calibrate" }
  { "action": "reboot" }


-------------------------------------------------------------------------------
[→ เว็บ]  ottobot/chat/in             คีย์ในไฟล์ตั้งค่า: TOPIC_CHAT_IN
-------------------------------------------------------------------------------
  ข้อความจากออตโต้บอทที่จะไปแสดงในกล่องแชท

  ส่งเป็นข้อความเปล่าก็ได้:      สวัสดีครับ ผมได้ยินเสียงคุณแล้ว
  หรือเป็น JSON:                { "text": "สวัสดีครับ", "face": "happy" }

  คีย์ที่เว็บยอมรับ: text, message, msg, speech, content, value

  สำคัญ  ถ้าเปิดสวิตช์ "ตอบหุ่นอัตโนมัติ" บนหน้าเว็บ (ค่าเริ่มต้น: เปิด)
         ข้อความที่เข้ามาทาง topic นี้จะถูกส่งให้ AI ตอบ แล้วเว็บจะส่งคำพูด
         กลับไปที่ ottobot/speech และคำสั่งท่าทางไปที่ ottobot/cmd ทันที
         ครบวงจร: หุ่นได้ยิน -> เว็บคิด -> หุ่นพูดและขยับ


-------------------------------------------------------------------------------
[→ เว็บ]  ottobot/face/state          คีย์ในไฟล์ตั้งค่า: TOPIC_FACE_STATE
-------------------------------------------------------------------------------
  สีหน้าปัจจุบันของหุ่น ใช้แสดงบนจอ LED มุมขวาบนของเว็บ

  ส่งเป็นข้อความเปล่า:  happy
  หรือเป็น JSON:       { "face": "happy" }

  คีย์ที่เว็บยอมรับ: face, emotion, expression, mood


-------------------------------------------------------------------------------
[→ เว็บ]  ottobot/status              คีย์ในไฟล์ตั้งค่า: TOPIC_STATUS
-------------------------------------------------------------------------------
  สถานะทั่วไปของหุ่น จะขึ้นเป็นข้อความแจ้งเตือนสั้น ๆ บนหน้าเว็บ

  { "battery": 88, "distance": 12, "temp": 31 }

  ใส่คีย์อะไรก็ได้ที่เป็นตัวเลข ข้อความ หรือ true/false
  ถ้ามีคีย์ face มาด้วย เว็บจะอัปเดตสีหน้ามุมขวาบนให้ด้วย


===============================================================================
  สีหน้าที่รองรับ (ใช้ได้ทั้งฟิลด์ face ทุกที่)
===============================================================================

  neutral      ปกติ
  happy        ยิ้ม
  sad          เศร้า
  angry        โกรธ
  surprised    ตกใจ
  love         รัก
  sleepy       ง่วง
  confused     งง
  wink         ขยิบตา
  cool         เท่

  ถ้าส่งค่าที่ไม่อยู่ในรายการนี้ เว็บจะไม่เปลี่ยนสีหน้า


===============================================================================
  คำสั่งท่าทางทั้งหมด (ฟิลด์ motion) - มี 13 คำสั่ง
===============================================================================

  walk         เดินหน้า
  back         เดินถอยหลัง
  left         เลี้ยวซ้าย
  right        เลี้ยวขวา
  home         ท่ายืนปกติ
  swing        โยกตัว
  updown       ย่อ-ยืด
  bend         ก้มตัว
  shake        สะบัดขา
  moonwalk     มูนวอล์ก
  wave         โบกมือ
  handsup      ยกมือขึ้น
  handdown     เอามือลง

  ชื่อคำสั่งต้องสะกดตรงตัวพิมพ์เล็กทั้งหมด
  เว็บจะไม่ส่งชื่ออื่นนอกเหนือจากนี้ออกมาเด็ดขาด


===============================================================================
  คำสั่งทดสอบด้วย mosquitto
===============================================================================

  # จำลองว่าหุ่นส่งข้อความเข้ามา
  mosquitto_pub -h localhost -t ottobot/chat/in -m 'สวัสดีครับ ผมออตโต้'

  # จำลองว่าหุ่นเปลี่ยนสีหน้า
  mosquitto_pub -h localhost -t ottobot/face/state -m 'love'

  # จำลองว่าหุ่นรายงานสถานะ
  mosquitto_pub -h localhost -t ottobot/status -m '{"battery":88}'

  # ดูทุกอย่างที่วิ่งผ่าน broker
  mosquitto_sub -h localhost -t 'ottobot/#' -v
